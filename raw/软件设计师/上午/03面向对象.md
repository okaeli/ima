## 继承
<img src="https://cdn.nlark.com/yuque/0/2024/png/8424314/1712880820127-46a4f6e8-e710-427f-8a82-58e7f4df4218.png" width="734.4444639005784" title="" crop="0,0,1,1" id="ue63497ef" class="ne-image">

### 特性
+ <font style="color:rgb(51, 51, 51);">子类拥有父类非 private 的属性、方法。</font>
+ <font style="color:rgb(51, 51, 51);">子类可以拥有自己的属性和方法，即子类可以对父类进行扩展。</font>
+ <font style="color:rgb(51, 51, 51);">子类可以用自己的方式实现父类的方法。</font>
+ <font style="color:rgb(51, 51, 51);">Java 的继承是单继承，但是可以多重继承，单继承就是一个子类只能继承一个父类，多重继承就是，例如 B 类继承 A 类，C 类继承 B 类，所以按照关系就是 B 类是 C 类的父类，A 类是 B 类的父类，这是 Java 继承区别于 C++ 继承的一个特性。</font>
+ <font style="color:rgb(51, 51, 51);">提高了类之间的耦合性（继承的缺点，耦合度高就会造成代码之间的联系越紧密，代码独立性越差）。</font>

### 关键字
<font style="color:rgb(51, 51, 51);">继承可以使用 extends 和 implements 这两个关键字来实现继承，而且所有的类都是继承于 java.lang.Object，当一个类没有继承的两个关键字，则默认继承 Object（这个类在 </font>**<font style="color:rgb(51, 51, 51);">java.lang</font>**<font style="color:rgb(51, 51, 51);"> 包中，所以不需要 </font>**<font style="color:rgb(51, 51, 51);">import</font>**<font style="color:rgb(51, 51, 51);">）祖先类。</font>

#### <font style="color:rgb(51, 51, 51);">extends关键字</font>
<font style="color:rgb(51, 51, 51);">在 Java 中，类的继承是单一继承，也就是说，一个子类只能拥有一个父类，所以 extends 只能继承一个类。</font>

```java
public class Animal { 
    private String name;   
    private int id; 
    public Animal(String myName, int myid) { 
        //初始化属性值
    } 
    public void eat() {  //吃东西方法的具体实现  } 
    public void sleep() { //睡觉方法的具体实现  } 
} 
 
public class Penguin  extends  Animal{ 
}
```

#### <font style="color:rgb(51, 51, 51);">implements关键字</font>
<font style="color:rgb(51, 51, 51);">使用 implements 关键字可以变相的使java具有多继承的特性，使用范围为类继承接口的情况，可以同时继承多个接口（接口跟接口之间采用逗号分隔）</font>

```java
public interface A {
    public void eat();
    public void sleep();
}
 
public interface B {
    public void show();
}
 
public class C implements A,B {
}
```

#### <font style="color:rgb(51, 51, 51);">super 与 this 关键字</font>
<font style="color:rgb(51, 51, 51);">super关键字：我们可以通过super关键字来实现对父类成员的访问，用来引用当前对象的父类。</font>

<font style="color:rgb(51, 51, 51);">this关键字：指向自己的引用。</font>

```java
class Animal {
  void eat() {
    System.out.println("animal : eat");
  }
}
 
class Dog extends Animal {
  void eat() {
    System.out.println("dog : eat");
  }
  void eatTest() {
    this.eat();   // this 调用自己的方法
    super.eat();  // super 调用父类方法
  }
}
 
public class Test {
  public static void main(String[] args) {
    Animal a = new Animal();
    a.eat();
    Dog d = new Dog();
    d.eatTest();
  }
}
```

#### <font style="color:rgb(51, 51, 51);">final 关键字</font>
<font style="color:rgb(51, 51, 51);">final 可以用来修饰变量（包括类属性、对象属性、局部变量和形参）、方法（包括类方法和对象方法）和类。</font>

<font style="color:rgb(51, 51, 51);">final 含义为 "最终的"。</font>

<font style="color:rgb(51, 51, 51);">使用 final 关键字声明类，就是把类定义定义为最终类，不能被继承，或者用于修饰方法，该方法不能被子类重写：</font>

```java
// 声明类
final class 类名 {//类体}

// 声明方法
修饰符(public/private/default/protected) final 返回值类型 方法名(){//方法体}
```

**<font style="color:rgb(51, 51, 51);">注：</font>**<font style="color:rgb(51, 51, 51);"> final 定义的类，其中的属性、方法不是 final 的。</font>

### <font style="color:rgb(51, 51, 51);">重写(Override)</font>
<font style="color:rgb(51, 51, 51);">重写是</font><font style="color:#DF2A3F;">子类对父类</font><font style="color:rgb(51, 51, 51);">的允许访问的方法的实现过程进行重新编写, 返回值和形参都不能改变。</font>**<font style="color:rgb(51, 51, 51);">即外壳不变，核心重写！</font>**

### <font style="color:rgb(51, 51, 51);">重载(Overload)</font>
<font style="color:rgb(51, 51, 51);">重载(overloading) 是在</font>**<font style="color:#DF2A3F;">一个类</font>**<font style="color:rgb(51, 51, 51);">里面，方法名字相同，而参数不同。返回类型可以相同也可以不同。</font>

<font style="color:rgb(51, 51, 51);">每个重载的方法（或者构造函数）都必须有一个独一无二的参数类型列表。</font>

<font style="color:rgb(51, 51, 51);">最常用的地方就是构造器的重载。</font>

# 可靠性，可用性，可维护性
<font style="color:rgb(0, 0, 0);background-color:rgb(254, 254, 242);">计算软件可靠性指标公式  
</font><font style="color:rgb(0, 0, 0);background-color:rgb(254, 254, 242);">可靠性：MTTF/(1+MTTF)  
</font><font style="color:rgb(0, 0, 0);background-color:rgb(254, 254, 242);">可用性：MTBF/(1+MTBF)  
</font><font style="color:rgb(0, 0, 0);background-color:rgb(254, 254, 242);">可维护性：1/(1+MTTR)</font>

<font style="color:rgb(0, 0, 0);background-color:rgb(254, 254, 242);">软件的可靠性是指一个系统在给定时间间隔内和给定条件下无失效运行的概率。  
</font><font style="color:rgb(0, 0, 0);background-color:rgb(254, 254, 242);">软件的可用性是指软件在特定使用环境下为特定用户用于特定用途时所具有的有效性。  
</font><font style="color:rgb(0, 0, 0);background-color:rgb(254, 254, 242);">软件的可维护性是指与软件维护的难易程度相关的一组软件属性。  
</font><font style="color:rgb(0, 0, 0);background-color:rgb(254, 254, 242);">软件的可伸缩性是指是否可以通过运行更多的实例或者采用分布式处理来支持更多的用户。</font>

<font style="color:rgb(0, 0, 0);background-color:rgb(254, 254, 242);">MTTF（Mean Time To Failure）平均无故障时间 MTTF =∑T1/ N  
</font><font style="color:rgb(0, 0, 0);background-color:rgb(254, 254, 242);">MTTR（Mean time to repair） 平均修复时间 MTTR =∑(T2+T3)/ N  
</font><font style="color:rgb(0, 0, 0);background-color:rgb(254, 254, 242);">MTBF (Mean Time Between Failure) 平均失效间隔 MTBF =∑(T2+T3+T1)/ N  
</font><font style="color:rgb(0, 0, 0);background-color:rgb(254, 254, 242);">MTBF= MTTF+ MTTR</font>

## 插入排序（稳定；不归位）
### 算法描述
<font style="color:rgb(34, 34, 34);">一般来说，插入排序都采用in-place在数组上实现。具体算法描述如下：</font>

+ <font style="color:rgb(34, 34, 34);">从第一个元素开始，该元素可以认为已经被排序；</font>
+ <font style="color:rgb(34, 34, 34);">取出下一个元素，在已经排序的元素序列中从后向前扫描；</font>
+ <font style="color:rgb(34, 34, 34);">如果该元素（已排序）大于新元素，将该元素移到下一位置；</font>
+ <font style="color:rgb(34, 34, 34);">重复步骤3，直到找到已排序的元素小于或者等于新元素的位置；</font>
+ <font style="color:rgb(34, 34, 34);">将新元素插入到该位置后；</font>
+ <font style="color:rgb(34, 34, 34);">重复步骤2~5</font>

### 动图演示
<img src="https://cdn.nlark.com/yuque/0/2024/gif/8424314/1712110286600-5245b6d9-50fe-4772-ba4e-903001d4ab66.gif" width="811" title="" crop="0,0,1,1" id="u11fbb9f6" class="ne-image">

### 代码实现
```java
public static void insertionSort(int[] arr) {
    if(arr == null || arr.length < 2) {
        return;
    }

    for(int i = 1; i < arr.length; i++) {
        // 记录当前要插入的值
        int current = arr[i];
        int j = i - 1;
        // 将大于current的值向右移动一位
        for(; j >= 0 && arr[j] > current; j--) {
            arr[j + 1] = arr[j];
        }
        // 将current放到正确位置
        arr[j + 1] = current;
    }
}
```



## 希尔排序（不稳定；不归位）
### 算法描述
<font style="color:rgb(34, 34, 34);">先将整个待排序的记录序列分割成为若干子序列分别进行直接插入排序，具体算法描述：</font>

+ <font style="color:rgb(34, 34, 34);">选择一个增量序列t1，t2，…，tk，其中ti>tj，tk=1；</font>
+ <font style="color:rgb(34, 34, 34);">按增量序列个数k，对序列进行k 趟排序；</font>
+ <font style="color:rgb(34, 34, 34);">每趟排序，根据对应的增量ti，将待排序列分割成若干长度为m 的子序列，分别对各子表进行直接插入排序。仅增量因子为1 时，整个序列作为一个表来处理，表长度即为整个序列的长度。</font>

### 代码实现
```java
public static void shellSort(int[] arr) {
    if (arr == null || arr.length < 2) {
        return;
    }
 
    int n = arr.length;
    // 初始增量n/2, 之后每次减半
    for (int gap = n / 2; gap >0; gap /= 2) {
        // 对每个子序列进行插入排序
        for (int i = gap; i<n ; i++) {
            // 插入排序的变体
            int current = arr[i];
            int j = i;
            for (;j >= gap && arr[j-gap] > current; j-= gap) {
                arr[j] = arr[j-gap];
            }
            arr[j] = current;
        }
    }
}
```

## 简单选择排序（不稳定；归位）
不稳定例子：

初始序列: [5_A, 3, 5_B, 2, 4] （这里5_A和5_B是值相等但是标识不同的元素）

在简单选择排序的第一轮中，我们找到最小元素2，并将其与第一个位置的5_A交换，得到：[2, 3, 5_B, 5_A, 4]

### 算法描述
<font style="color:rgb(34, 34, 34);">n个记录的直接选择排序可经过n-1趟直接选择排序得到有序结果。具体算法描述如下：</font>

+ <font style="color:rgb(34, 34, 34);">初始状态：无序区为R[1..n]，有序区为空；</font>
+ <font style="color:rgb(34, 34, 34);">第i趟排序(i=1,2,3…n-1)开始时，当前有序区和无序区分别为R[1..i-1]和R(i..n）。该趟排序从当前无序区中-选出关键字最小的记录 R[k]，将它与无序区的第1个记录R交换，使R[1..i]和R[i+1..n)分别变为记录个数增加1个的新有序区和记录个数减少1个的新无序区；</font>
+ <font style="color:rgb(34, 34, 34);">n-1趟结束，数组有序化了。</font>

### 代码实现
```java
public static void selectionSort(int[] arr) {
    if (arr == null || arr.length < 2) {
        return;
    }

    for (int i = 0; i < arr.length - 1; i ++) {
        // 假设当前位置位最小值
        int minIndex = i;
        // 在未排序的区间找到最小值索引
        for (int j = i +1; j < arr.length && arr[j] < arr[minIndex]; j++ ) {
            minIndex = j;
        }
        // 如果最小值索引不是当前位置
        if (minIndex != i) {
            int temp = arr[i];
            arr[i] = arr[minIndex];
            arr[minIndex] = temp;
        }
    }
}
```

## 堆排序（不稳定；归位）
<details class="lake-collapse"><summary id="u2fc898b0"><span class="ne-text">如何计算堆的最后一个非叶子节点</span></summary><p id="u43ebd9b5" class="ne-p"><span class="ne-text" style="color: rgba(255, 255, 255, 0.7); font-size: 14px">在</span><span class="ne-text" style="background-color: #FFFFFF; font-size: 14px">完全二叉树（或堆）中，如果我们按照从上到下、从左到右的顺序对节点进行编号（从0开始），那么对于任意一个节点i：</span></p><ol class="ne-ol"><li id="u1ab0e710" data-lake-index-type="0"><span class="ne-text" style="background-color: #FFFFFF; font-size: 14px">它的左子节点的编号是</span><span class="ne-text" style="background-color: #FFFFFF; font-size: 14px"> </span><span class="ne-text" style="background-color: #FFFFFF; font-size: 14px">2*i + 1</span></li><li id="u45959c21" data-lake-index-type="0"><span class="ne-text" style="background-color: #FFFFFF; font-size: 14px">它的右子节点的编号是</span><span class="ne-text" style="background-color: #FFFFFF; font-size: 14px"> </span><span class="ne-text" style="background-color: #FFFFFF; font-size: 14px">2*i + 2</span></li><li id="ue7dcb84d" data-lake-index-type="0"><span class="ne-text" style="background-color: #FFFFFF; font-size: 14px">它的父节点的编号是</span><span class="ne-text" style="background-color: #FFFFFF; font-size: 14px"> </span><span class="ne-text" style="background-color: #FFFFFF; font-size: 14px">(i-1)/2</span><span class="ne-text" style="background-color: #FFFFFF; font-size: 14px">（这里假设</span><span class="ne-text" style="background-color: #FFFFFF; font-size: 14px">i</span><span class="ne-text" style="background-color: #FFFFFF; font-size: 14px">是从0开始的编号）</span></li></ol><p id="ubfbd6844" class="ne-p"><span class="ne-text" style="background-color: #FFFFFF; font-size: 14px">这种编号方式是基于数组实现的堆数据结构的基础。</span></p><p id="u49073844" class="ne-p"><span class="ne-text" style="background-color: #FFFFFF; font-size: 14px">接下来，让我们找出最后一个非叶子节点的位置：</span></p><ul class="ne-ul"><li id="ub4987aad" data-lake-index-type="0"><span class="ne-text" style="background-color: #FFFFFF; font-size: 14px">在完全二叉树中，最后一个节点（假设其编号为</span><span class="ne-text" style="background-color: #FFFFFF; font-size: 14px">n-1</span><span class="ne-text" style="background-color: #FFFFFF; font-size: 14px">，其中</span><span class="ne-text" style="background-color: #FFFFFF; font-size: 14px">n</span><span class="ne-text" style="background-color: #FFFFFF; font-size: 14px">是节点总数，也就是数组的长度）的父节点，就是最后一个非叶子节点。</span></li><li id="u77244245" data-lake-index-type="0"><span class="ne-text" style="background-color: #FFFFFF; font-size: 14px">根据父节点的编号计算公式，我们可以推算出最后一个非叶子节点的编号为 ((n-1)-1)/2 = n/2 - 1。</span></li></ul></details>
### 算法描述
+ <font style="color:rgb(34, 34, 34);">将初始待排序关键字序列(R1,R2….Rn)构建成大顶堆，此堆为初始的无序区；</font>
+ <font style="color:rgb(34, 34, 34);">将堆顶元素R[1]与最后一个元素R[n]交换，此时得到新的无序区(R1,R2,……Rn-1)和新的有序区(Rn),且满足R[1,2…n-1]<=R[n]；</font>
+ <font style="color:rgb(34, 34, 34);">由于交换后新的堆顶R[1]可能违反堆的性质，因此需要对当前无序区(R1,R2,……Rn-1)调整为新堆，然后再次将R[1]与无序区最后一个元素交换，得到新的无序区(R1,R2….Rn-2)和新的有序区(Rn-1,Rn)。不断重复此过程直到有序区的元素个数为n-1，则整个排序过程完成。</font>

### 动图演示
<img src="https://cdn.nlark.com/yuque/0/2024/gif/8424314/1712114616289-f40fae60-19eb-426a-a00a-de393d78260b.gif" width="547" title="" crop="0,0,1,1" id="uafd34dd1" class="ne-image">

### 代码实现
```java
public static void heapSort(int[] arr) {
    if (arr == null || arr.length <= 1) return;

    //1. 构造大顶堆
    buildMaxHeap(arr);
    for (int i = arr.length -1; i >=1; i--) {
        // 2. 将堆顶元素（当前最大值）与数组末尾元素交换
        swap(arr, 0, i);
        // 3. 将剩余的堆继续调整为最大堆
        maxHeapify(arr, 0, i);
    }

}

// 构造大顶堆
private static void buildMaxHeap(int[] arr) {
    // 从最后一个非叶子结点开始，向前调整所有节点
    for (int i = arr.length / 2 -1; i >=0 ; i--) {
        maxHeapify(arr, i, arr.length);
    }
}

// 调整节点使其成为大顶堆
private static void maxHeapify(int[] arr, int i, int heapSize) {
    int left = 2 * i + 1; // 左子节点索引
    int right = 2 * i + 2; // 右子节点索引
    int largest = i; // 假设当前节点（父节点）是最大的
    // 如果左子节点大于父节点，则更新最大节点索引
    if (left < heapSize && arr[left] > arr[largest]) {
        largest = left;
    }
    // 如果右子节点大于当前最大节点，则更新最大节点索引
    if (right < heapSize && arr[right] > arr[largest]) {
        largest = right;
    }
    // 如果最大节点不是父节点，交换它们，并递归调整被破坏的子堆
    if (largest != i) {
        swap(arr, i, largest);
        maxHeapify(arr, largest, heapSize);
    }
}

// 交换数组中的两个元素
private static void swap(int[] arr, int i, int j) {
    int temp = arr[i];
    arr[i] = arr[j];
    arr[j] = temp;
}
```

## 冒泡排序（稳定；归位）
### 算法描述
+ <font style="color:rgb(34, 34, 34);">比较相邻的元素。如果第一个比第二个大，就交换它们两个；</font>
+ <font style="color:rgb(34, 34, 34);">对每一对相邻元素作同样的工作，从开始第一对到结尾的最后一对，这样在最后的元素应该会是最大的数；</font>
+ <font style="color:rgb(34, 34, 34);">针对所有的元素重复以上的步骤，除了最后一个；</font>
+ <font style="color:rgb(34, 34, 34);">重复步骤1~3，直到排序完成。</font>

### 动图演示

### 代码实现
```java
public static void bubbleSort(int[] arr) {
    if (arr == null || arr.length < 2) {
        return;
    }
    // 外层循环，控制遍历次数
    for (int i =0;i<arr.length-1;i++) {
        // 标记是否交换过，没有交换过说明队列有序，直接返回
        boolean flag = false;
        // 内层循环，进项相邻元素比较和交换
        // arr.length -i -i 是因为每遍历一次，最大的元素就会“冒泡”到数组末尾，因此每次比较的范围是可以减少的
        for (int j =0; j<arr.length - 1 -i; j ++) {
            // 如果前一个元素大于后一个元素，交换位置
            if (arr[j] > arr[j+1]) {
                int temp = arr[j];
                arr[j] = arr[j+1];
                arr[j+1] = temp;
                flag = true;
            }
        }
        
        if (!flag) return;
    }
}
```

## 快速排序（不稳定，归位）
每次排序可以确定基准元素的位置

快速排序是一种分治算法，它通过一个基准值（pivot）将数组分成两部分，然后递归地对这两部分进行快速排序。快速排序的空间复杂度主要来自于递归调用的栈空间。

+ 在最好的情况下，每次分区都能将数组划分为大小几乎相等的两部分，这意味着递归树的深度大约为log(n)，因此空间复杂度为O(log(n))。
+ 在最坏的情况下，如果每次分区操作总是选取到最小或最大的元素作为基准值，这将导致递归树的深度为n，从而空间复杂度为O(n)。

### 算法描述
<font style="color:rgb(34, 34, 34);">快速排序使用分治法来把一个串（list）分为两个子串（sub-lists）。具体算法描述如下：</font>

+ <font style="color:rgb(34, 34, 34);">从数列中挑出一个元素，称为 “基准”（pivot）；</font>
+ <font style="color:rgb(34, 34, 34);">重新排序数列，所有元素比基准值小的摆放在基准前面，所有元素比基准值大的摆在基准的后面（相同的数可以到任一边）。在这个分区退出之后，该基准就处于数列的中间位置。这个称为分区（partition）操作；</font>
+ <font style="color:rgb(34, 34, 34);">递归地（recursive）把小于基准值元素的子数列和大于基准值元素的子数列排序。</font>

### 动图演示
[此处为语雀卡片，点击链接查看](https://www.yuque.com/nathan-kd4ra/soft_exam/ai8k2sllxu39fkhz#wsqkL)

### 代码实现
```java
public static void quickSort(int[] arr, int low, int high) {
    if (low < high) {
        // pi是分区后的基准值的索引
        int pi = partition(arr, low, high);

        // 递归排序基准值左边的子数组
        quickSort(arr, low, pi - 1);
        // 递归排序基准值右边的子数组
        quickSort(arr, pi + 1, high);
    }
}

private static int partition(int[] arr, int low, int high) {
    // 选择最后一个元素作为基准值
    int pivot = arr[high];
    int i = (low - 1); // i是小于基准值元素的区域的边界

    for (int j = low; j < high; j++) {
        // 当前元素小于或等于基准值
        if (arr[j] <= pivot) {
            i++;

            // 交换arr[i]和arr[j]
            int temp = arr[i];
            arr[i] = arr[j];
            arr[j] = temp;
        }
    }

    // 将基准值放到正确的位置
    int temp = arr[i + 1];
    arr[i + 1] = arr[high];
    arr[high] = temp;

    return i + 1;
}
```

## 归并排序 （稳定，不归位）
### 算法描述
+ <font style="color:rgb(34, 34, 34);">把长度为n的输入序列分成两个长度为n/2的子序列；</font>
+ <font style="color:rgb(34, 34, 34);">对这两个子序列分别采用归并排序；</font>
+ <font style="color:rgb(34, 34, 34);">将两个排序好的子序列合并成一个最终的排序序列。</font>

### 动图演示

### 代码实现
```java
public static void sort(int[] arr, int l, int r) {
    if (l < r) {
        // 找到中间索引
        int m = (l + r) / 2;

        // 对左半部分排序
        sort(arr, l, m);
        // 对右半部分排序
        sort(arr, m + 1, r);

        // 合并两部分
        merge(arr, l, m, r);
    }
}

// 合并两个子数组的方法
public static void merge(int[] arr, int l, int m, int r) {
    // 计算子数组的大小
    int n1 = m - l + 1;
    int n2 = r - m;

    // 创建临时数组
    int[] L = new int[n1];
    int[] R = new int[n2];

    // 将数据复制到临时数组中
    for (int i = 0; i < n1; ++i)
    L[i] = arr[l + i];
    for (int j = 0; j < n2; ++j)
    R[j] = arr[m + 1 + j];

    // 合并临时数组

    // 初始化索引
    int i = 0, j = 0;

    // 初始化合并数组的起始索引
    int k = l;
    while (i < n1 && j < n2) {
        if (L[i] <= R[j]) {
            arr[k] = L[i];
            i++;
        } else {
            arr[k] = R[j];
            j++;
        }
        k++;
    }

    // 复制剩余的左侧元素
    while (i < n1) {
        arr[k] = L[i];
        i++;
        k++;
    }

    // 复制剩余的右侧元素
    while (j < n2) {
        arr[k] = R[j];
        j++;
        k++;
    }
}
```

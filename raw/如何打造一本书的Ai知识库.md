整体流程：资料整理 → AI 加工 → 知识结构化 → 上传知识库

一个真正可用的知识库，需要提前对内容进行加工：
- 把原书内容脱水提炼
- 重新建立知识结构 
- 补充用户真实问题
- 加入场景化案例

下面分享完整制作流程。你可以按照这个流程，把《毛选》制作成一个可以问答的 AI 知识库。

# 第一步：准备《毛选》原始资料

首先准备电子版资料。来源可以是：PDF、EPUB、TXT 如果 PDF 是扫描版，需要先 OCR 转文字。

建议最终整理成 Markdown 格式。因为 Markdown 的结构更适合 AI 理解。

整理成：

```
## 实事求是

核心观点：
实事求是强调从实际情况出发，通过调查研究认识客观规律。

来源：
《改造我们的学习》

关键词：
实事求是
调查研究
实践
```

# 第二步：清洗原始内容

拿到原始文本后，先进行清洗。 
需要删除：页码、水印、出版信息、重复目录、OCR 错误、无意义注释 目的是得到干净的正文内容

如果直接把带大量格式垃圾的 PDF 上传，AI 很容易出现： 引用错误、上下文混乱、找不到重点等问题

# 第三步：对《毛选》进行知识脱水（最重要的一步）

这是整个知识库制作的核心。需要把原文转换成： 用户问题 → 核心观点 → 解释 → 实际应用

例如： 原文：“没有调查，没有发言权。”

转换后： 用户问题：为什么很多创业者容易做错误判断？

核心观点： 决策不能建立在主观想象上，需要基于真实情况分析。

详细解释： 很多错误来自于没有了解真实环境，只根据自己的经验和假设判断。

实际应用： 创业前先访谈用户、测试需求，而不是直接投入大量资源。

来源：《反对本本主义》 标签：调查研究、决策、创业分析

这样 AI 后续才能回答：创业方向怎么判断？ 而不是只返回一句原文。

知识脱水 Prompt（直接复制）

```markdown
你是一名专业 AI 知识库工程师。
我要把《毛泽东选集》制作成一个 AI 问答知识库。
请对下面内容进行知识脱水和结构化处理。
不要简单总结文章。

请转换成适合 AI 问答的数据格式。

输出格式：

【用户问题】
模拟真实用户可能提出的问题。

【核心观点】
提炼原文最重要的思想。

【详细解释】
解释这个观点背后的逻辑。

【现实应用】
结合现代：
职场
创业
个人成长
决策
等场景说明如何使用。

【原文来源】
标注对应章节。

【关键词】
方便 AI 检索。

要求：
1. 保留原著核心思想。
2. 不添加未经验证的观点。
3. 不按照原章节总结，要按照用户需求组织。
4. 问题必须像真实用户咨询。
   
内容：
{{输入原文}}
```

# 第四步：建立知识库目录结构

不要按照《毛选》的章节建立目录，因为用户不会按照章节提问。

建议重新划分：

1\. 思维方法

包含：
* 实事求是
* 调查研究
* 认识规律

用户问题：
*  如何提高判断能力？
*  为什么我的分析经常错误？

2\. 决策方法

包含：
* 矛盾分析
* 主要矛盾
* 战略判断
* 
用户问题：
*  如何选择方向？
*  如何分析复杂问题？
* 
3\. 行动方法

包含： 
*   实践
*   反馈
*   调整

用户问题：
*  为什么知道方法却执行不了？
*  如何提高行动力？

4\. 组织管理

包含：
*  群众路线
*  团队管理
*  组织建设

用户问题：
*  如何管理团队？
*  如何建立影响力？

# 第五步：生成用户问答数据

除了知识卡片，还需要提前生成大量真实问题。

  

因为用户不会问：“解释一下矛盾论。” 他们会问：“我现在有两个机会，应该怎么选择？”

  

所以需要生成：用户问题 + AI答案。

  

使用 Prompt：

  

markdown

  

```markdown

你是一名 AI 问答数据训练专家。

请根据下面的毛选知识内容，生成100条真实用户可能提出的问题。

  
  

问题方向：

1. 职场成长

  

例如：

如何面对竞争？

如何提高自己的判断能力？

  
  

2. 创业决策

  

例如：

创业初期应该关注什么？

如何判断一个机会？

  
  

3. 人生选择

  

例如：

如何面对长期不确定？

如何做重要决定？

  
  

4. 问题分析

  

例如：

如何找到真正的问题？

如何判断事情优先级？

  
  

每条输出：

用户问题：

AI回答：

对应毛选思想：

来源章节：

关键词：

  

要求：

不要生成考试题。

模拟真实用户咨询。

  

回答需要：

先给结论，

再解释原因，

最后给行动建议。

```

# 第六步：上传腾讯 ima 创建知识库

  
  

======================

  

内容整理完成后，就可以进入腾讯 ima。

  

1\. 创建知识库

  

打开 ima 创建新的知识库 名称可以设置：「毛选思维 AI 智库」

![[IMA.png]]

  

2\. 上传文件

  

不要直接上传原 PDF。 上传整理后的文件：

  

```text

01_核心知识.md

02_问题库.md

03_案例应用.md

04_知识卡片.md

```

  

3\. 设置 AI 回复规则

  

添加知识库提示词：

  

markdown

  

```markdown

你是一名毛选思维顾问。

  

回答用户问题时：

  

第一步：

分析用户真实问题。

  

第二步：

调用知识库中的相关观点。

  

第三步：

结合现代场景解释。

  

第四步：

给出可执行建议。

  

回答格式：

核心观点：

原因分析：

现实应用：

行动建议：

  
  

要求：

不要脱离知识库编造内容。

不要只复制原文。

必须结合用户具体问题回答。

```

# 第七步：测试和优化知识库

完成后不要马上发布，先测试真实问题。

  

这时候可以去小红书找找用户真实痛点，找学业、职场、原生家庭之类的问题，小红书笔记评论区看别人吐槽也能发现不少需求

  

也可以直接搜索：毛选+场景词/长尾词 看看近半年的爆款笔记（高赞评论收藏），从笔记和评论区中找真实场景，再做成实际问题


  

问题参考： 工作几年没有成长怎么办？ 创业方向很多怎么选择？ 为什么我努力很多却没有结果？ 团队成员执行力差怎么办？ 刚进公司怎么跟同事熟络起来？

  

检查 AI 输出：

  

1.  是否找到正确知识？

2.  是否理解用户场景？

3.  是否给出具体建议？

  

如果回答不好，不要急着换模型。 通常需要优化：知识内容、标签、问题库、提示词

  

总结

  
  

======

  

制作一个毛选 AI 问答知识库，核心流程就是： 原始 PDF → 内容清洗 → 知识脱水 → 问题重构 → 知识结构化 → 上传 ima → 测试优化

  

真正影响效果的不是 AI 模型，而是前面的内容加工。

  

按照这套流程，不只是《毛选》，任何一本书、课程资料、行业报告，都可以制作成自己的 AI 问答知识库。

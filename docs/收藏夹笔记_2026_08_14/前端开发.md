# 前端开发 — 转盘抽奖组件

**Summary:** 收集两个开源转盘抽奖组件示例，便于参考实现与复用。  
**Tags:** 前端, Vue, React, CSS, 组件

## 3. ESnail/turntable（h5 转盘抽奖）

- 链接： https://github.com/ESnail/turntable
- 平台：GitHub
- 技术栈：CSS + 原生 JS / Vue / React
- 简介：H5 页面转盘抽奖组件，分别用 CSS+JS、Vue、React 三种方式实现。Vue 版已应用于实际项目，React 版为练手。CSS+JS 版纯布局实现（闪烁灯、转盘、指针），未使用任何图片。
- 预览： Vue 版 / CSS+JS 版 / React 版（见仓库的 gh-pages 链接）
- 最后更新：2019-05-30

## 4. landluck/lucky_wheel（Vue 抽奖大转盘）

- 链接： https://github.com/landluck/lucky_wheel
- 平台：GitHub
- 技术栈：Vue 2 + Webpack
- 简介：使用 Vue 开发的简单转盘抽奖组件，支持奖项动态配置。提供简单的旋转逻辑和奖项位置的动态计算，默认采用八个奖项的转盘背景，使用者可通过更换背景图片改变奖项数量。
- 预览： https://www.landluck.com.cn/web/wheel/index.html
- 最后更新：2020-04-26

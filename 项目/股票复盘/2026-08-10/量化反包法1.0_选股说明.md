## 一、什么是"量化反包法 1.0"

- **底层认知**：主讲人认为当前市场完全由**量化资金主导**，而"所有的量化都是通过**图形和量能**去选出（标的）"的。所以**选股要把"图形"放在第一顺位**——图形好，量化才敢拉。
- **1.0 的定位（总纲版）**：1.0 不像 2.0 那样专门限定"弱势行情 + 低位题材"，而是一套更**广谱的打法总纲**：「**图形第一 → 找量化介入的板块 → 分时次日低吸（反包）**」。
- **与 2.0 的关系**：1.0 偏"趋势/主升浪里的分时反包"，2.0 是在 1.0 基础上更聚焦"弱势低位题材的连板断板反包"，并把**集合竞价红柱**作为最终买点闸门加进来（详见第五节对比）。

## 三、选股：具体怎么挑（三大模块详解）

主讲人把方法拆成**三大模块**，可归纳为一个流程：
**先看图形 → 再锁定量化介入的板块 → 最后在分时次日低吸（反包）执行**。

### 模块一：选股把"图形"放第一顺位

- **图形是量化选股的第一要素**：量化看图施工，图形好它才敢拉；图形差，再好的故事也难持续。
- **超短选手以"一进二"为主**：主讲人自称超短（超端）选手，日常主要做 1 板进 2 板。
- **首选"右侧多头排列"**：均线多头上扬、主升信号强时，才去博弈。右侧行情（包括大盘右侧多头排列时）"极为好做"。
- **右侧信号偏延后、风险不小说**：右侧收益高但风险也不小，属于"收益高风险也不小"的博弈。
- **新手通病（重点警示）**：
  - 右侧主升浪**不敢买**，左侧（下跌）**死拿**；
  - **涨一点就跑、跌一点就扛**，完全不看图形；
  - 结果量化"根据图形施工，早就跑路把散户挂山顶去了"。

### 模块二：找"量化介入"的板块（看成交量 / 量能）

- **并非每个板块量化都会趋势性拉升**：市场虽量化主导，但量化只在深度介入的板块做趋势。
- **量化踪迹 = 成交量**：
  - 板块**量能趋势放大** + **涨停家数多** + **大容量（大屁股）涨停**；
  - 当**溢价反馈到大容量票、把大容量顶到涨停**，就明显是量化介入板块/题材造成的。
- **量能与资金的关系**：
  - 板块/题材量能放大 = 资金逐渐介入；**缩量 = 逐渐流出**；
  - **资金介入越深，结束越慢；介入越久，题材趋势性越久**；
  - 还会带动各种**细分补涨**，最后形成大家常说的"主线"。
- **选股看板块有没有"趋势性"**：有没有"**小票连板 + 大容量涨停**"的组合。
- **视频点名的历史主线板块**：半导体、电力、"煤炭"（防手煤炭→煤炭）等。
- **口诀**：**"个股强不一定真的强，板块强才是真的强"**——板块量化深度介入后，趋势性通常比较强。

### 模块三：买点——"分时次日低吸"（反包的核心执行）

这是 1.0 的精髓，也是"反包"二字的具体落地动作。

- **成功案例（视频点名）**：华芳、达什、步步高（来自一位游资朋友），以及主讲人自己做的**金石**；另外还有**福达、风华、魔素**作为买点示范。
- **盈亏比理念**：小概率亏小钱，大概率赚大钱——靠的就是"买在分时转强一截"的节奏。
- **核心机理**：
  - 断板/分歧次日，**分时通常会延续前一天的分歧**，早上往往有一波**惯性下杀（下探）**；
  - 这波下杀，就是低吸（反包）的机会。
- **标准打法（两步）**：
  1. **在五日均线附近"敲底"（低吸）**；
  2. 等**快速拉红（分时转强一截）再加一笔**。
- **选股再细化（提高胜率）**：
  - 选**走出趋势的**，或**二板三板断板**的（量化介入多、介入久）；
  - **断板当天要给"高溢价"**；**千万别买那种断板低开、连冲高溢价都没有的**——量化看不到溢价，买入概率大降。
- **次日"高开"的两种处理（很关键）**：
  - **高开低走**：说明分时延续分歧，买点推后；**高开高走也别急**，大概率还会回落分时一下，**在开盘价附近买入即可**（例：福达"高开冲高回落"，在开盘价附近低吸；风华也是冲高回落后又拉高）。
  - **硬性条件**：必须是"**开盘高开、冲高好几个点回落**"才去低吸。
  - **反面教材（魔素）**：高开只拉一点点就回落 = 分歧很大，可在**涨幅 >5% 或五日均线附近**找买点，**快速拉红转一截再买**；如果**拉得慢就算了**（放弃）。

## 四、1.0 选股决策清单（一句话汇总）

1. **图形第一**：右侧多头排列 / 主升信号（新手的雷区是右侧不敢买、左侧死拿）。
2. **锁定板块**：找量化深度介入的——量能趋势放大 + 小票连板 + 大容量涨停；**板块强才是真强**。
3. **挑个股**：走出趋势，或**二板三板断板**，且断板当天给**高溢价**。
4. **定买点**：**分时次日**（早上惯性下杀后）低吸，五日均线附近敲底，快速拉红转一截再加仓。
5. **高开法则**：必须"高开冲高回落"才低吸；低开、无溢价的不碰。
6. **叠加维度**：结合**大盘情况、题材预判、个股辨识度、板块地位**。
7. **铁律**：**不要传播**——"知道的人越多、用的人越多，赚钱越少"（alpha 衰减）。

## 五、1.0 vs 2.0 对比（同一套战法的两个版本）

| 维度 | 量化反包法 **1.0**（本视频） | 量化反包法 **2.0** |
|---|---|---|
| 适用行情 | **不限定弱势**，偏趋势/主升浪里的分时反包 | 明确强调 **弱势行情 + 低位题材** |
| 选股起点 | **图形第一** + 找量化介入板块（量能） | 板块小梯队**龙头** + 2–3 板断板 |
| 核心买点 | **分时次日低吸**：五日均线附近敲底，快速拉红转一截加仓 | 次日五日均线附近低吸（低开小买、久站不上则避） |
| 买点确认 | 看"高开冲高回落 / 拉红转一截" | 额外加 **集合竞价红柱**（买量>卖量=抢筹）作最终闸门 |
| 避雷侧重 | 低开无溢价不碰、拉得慢放弃、图形差不碰 | 长下影线（对手盘重）、后排杂毛、获利盘过多 |
| 共同内核 | 都讲 **2–3 板断板、五日均线低吸、算对手盘、不要传播** | 同左，是 1.0 的精细化/场景化版本 |

**一句话**：1.0 是"广谱总纲"（图形+量化板块+分时低吸），2.0 是"弱市专精版"（低位题材断板反包 + 竞价确认）。两者底层逻辑一致，2.0 多了"弱势/低位"前提和"竞价红柱"这道确认闸门。

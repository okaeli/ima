## 关键经验
- 断板日"主力不撤"是最硬核的证据，资金流比形态重要得多
- 断板日主力流出+散户流入=出货结构，直接放弃
- **反包日二次确认更重要：断板日主力流出≠必然出货，反包日若主力大额回流(超大单转正)即为"出而后返"，是强反包信号（哈药股份8/13实证）**
- 连板后偏离MA5通常在+6%~+17%，实操中"贴MA5"理解为反包日回踩买点区
